# 双向云桥 · 使用指南

适用版本：OpenList Transfer 1.0.0 / Windows 10、11 x64 / 内置 OpenList v4.2.6

更新日期：2026-09-29

## 一、第一次使用

双向云桥把夸克和 115 放在同一个桌面窗口中，支持选择文件或整个文件夹，通过这台电脑复制到另一侧网盘。源文件保留，子目录和空文件夹也会纳入任务。

**传输路线：来源网盘 → 电脑缓存 → 目标网盘 → 核对结果 → 清理本次文件缓存。**

### 准备好这三样

- Windows 10 或 11 的 64 位电脑，以及 `OpenListTransfer-1.0.0-x64.exe`。运行 EXE 不需要另装 Node.js 或 OpenList。GitHub 的“Download ZIP”下载的是源码，不能直接当 EXE 运行。
- 你自己的夸克、115 账号；确认能够在各自官方网页或客户端访问文件，目标网盘有足够容量。
- 稳定网络和空间充足的本地磁盘。传输期间保持电脑开机联网；合盖、睡眠、关机或退出程序都会影响传输。

### 六步开始

1. 双击 EXE，等待右上角出现“本地服务运行中”。首次展开运行文件可能需要一些时间。
2. 左右两侧分别点击“连接账号”，完成登录。两边应显示“已连接”，并能读取文件列表。
3. 点击右上角“设置”→“选择目录”，选择空间充足的位置作为缓存。
4. 在来源侧勾选文件或文件夹；在目标侧进入接收文件的目录。
5. 点击中间“到 115”或“到夸克”，核对“从”“到”，点击“开始复制”。
6. 在“传输任务”中等待“已完成”，刷新目标列表，并到目标网盘打开几个文件检查。

**首次先复制少量测试文件。** 当前版本已通过本地引擎、任务队列和界面测试，但尚未使用真实夸克 / 115 账号完成端到端测试。登录、传输速度和可用性仍受网盘接口及账号状态影响。

### 找到操作入口

| 界面位置 | 用途 |
| --- | --- |
| 左侧“夸克网盘” | 浏览夸克文件，选择夸克作为来源或目标 |
| 右侧“115 网盘” | 浏览 115 文件，选择 115 作为来源或目标 |
| 中间两个方向按钮 | “到 115”：左到右；“到夸克”：右到左 |
| 下方“传输任务” | 查看进度、失败原因，暂停、继续、重试或取消 |
| 右上角“设置” | 选择缓存目录，打开缓存或应用数据目录 |

阅读顺序：账号连接 → 复制文件 → 任务恢复 → 缓存与数据 → 常见问题。PDF 与本页正文一致。

## 二、连接夸克和 115

### 夸克：优先网页登录

1. 在左侧点击“连接账号”→“打开扫码 / 网页登录”。
2. 程序会打开独立登录窗口，访问夸克网盘官网。按页面提供的方式登录；需要扫码时，用自己的手机确认。
3. 完成后程序自动尝试读取登录状态并验证目录。接入成功时登录窗口会关闭，主界面显示“已连接”。
4. 若始终未连接，回到账号窗口，使用“手动凭证”方式。

### 夸克：手动填写 Cookie

1. 用 Chrome 打开 [夸克网盘官网](https://pan.quark.cn)，登录自己的账号。
2. 按 `F12` 打开开发者工具，进入“网络 / Network”，刷新网盘页面或打开一个文件夹。
3. 选择网盘的已登录请求，在“请求标头 / Request Headers”中找到 `Cookie`，复制其完整值，不要只复制其中一个字段。
4. 回到软件左侧账号窗口，展开“使用手动凭证”，粘贴到 `Cookie`，点击“保存并连接”。

获取方式参考 [OpenList 普通夸克驱动说明](https://doc.oplist.org/guide/drivers/quark)。本应用使用普通夸克驱动，填写 Cookie 即可。

### 115：完成 OpenList 授权

1. 在右侧点击“连接账号”→“打开扫码 / 网页登录”。程序打开的是 [OpenList 授权工具](https://api.oplist.org)，不是直接打开 115 文件列表。
2. 在网页中选择 115 网盘授权入口。按官方文档，使用公共参数时，勾选“使用 OpenList 提供的参数”，客户端 ID 和应用密钥留空，再点击“获取 Token”。
3. 在弹出的 115 登录页面完成本人登录并确认授权，返回授权结果页面。
4. 程序会尝试导入令牌并读取网盘目录。主界面显示“已连接”且文件列表可读，即可继续。

上述网页选项以当时页面为准，操作依据 [OpenList 115 Open 驱动说明](https://doc.oplist.org/guide/drivers/115_open)。OpenList 授权工具属于 OpenList 项目，115 登录和授权在其跳转的 115 页面完成。

### 115：手动填写两种 Token

自动导入失败时，在上述授权结果页面复制 **Access Token** 和 **Refresh Token**。回到右侧账号窗口，展开“使用手动凭证”，分别粘贴到同名输入框，再点击“保存并连接”。两个字段都必须填写；此处不使用 115 Cookie，也不填写账号密码。

已连接后，按钮会变成“管理账号”，可重新授权或更新凭证。任务尚未完成时，请保持原账号；切换到另一个账号会改变原任务对应的网盘内容。

Cookie、Token 和授权回调地址可能包含登录凭证，请勿发到群聊、问题反馈或代码仓库。

### 退出当前账号

在对应网盘点击“管理账号”→“退出当前账号”，在确认窗口点击“退出账号”。若账号已失效或显示尚未连接，也可从“连接账号”进入同一退出入口。

退出会移除该网盘在本软件中的凭证、网页登录状态和文件列表，另一侧账号、云端文件及任务历史保留。再次使用时重新登录；Chrome 和官方客户端的登录不受影响，网盘端应用授权也不会被撤销。

如有未完成任务（包括暂停和失败），请先完成或取消，并等待取消收尾。退出后已取消的旧任务不能重试，换账号后应重新选择文件创建任务。若提示“退出未完全完成”，请按提示再次退出。

## 三、选择文件并双向复制

### 先分清“进入”和“选择”

- **进入文件夹**：点击文件夹名称。点击上方“全部文件”、路径中的目录名或向上箭头，可以切换目录；圆形箭头用于刷新。
- **选择要复制的项目**：勾选项目左侧复选框。表头复选框选择当前目录中的全部项目；勾选文件夹会把其子目录一并纳入任务。
- **切换目录会清空该侧选择**。需要一次复制多个文件夹时，回到它们共同的上级目录，再勾选它们。
- **目标是另一侧当前打开的目录**。只勾选目标文件夹不会进入它；请先点击文件夹名称。

### 示例 A：把夸克的“照片”复制到 115 的“备份”

1. 左侧进入“照片”的上级目录，勾选“照片”。
2. 右侧点击“备份”文件夹名称，进入“备份”。若目录还不存在，先用 115 官方网页或客户端创建，再刷新这里的列表。
3. 点击中间“到 115”。在确认窗口检查来源、目标路径和选中项目数量。
4. 点击“开始复制”。完成后，目标位置为 `115 / 备份 / 照片`。

若只想复制“照片”里面的内容，则先进入左侧“照片”，勾选其中的项目。这样会把这些项目直接放进右侧“备份”，不会再套一层“照片”。

### 示例 B：把 115 的文件复制到夸克

在右侧勾选来源文件或文件夹，在左侧进入目标目录，点击“到夸克”，检查路径后点击“开始复制”。两种方向的重名、缓存和核验规则相同。

### 同名项目怎样处理

| 目标已有内容 | 新复制内容 | 处理结果 |
| --- | --- | --- |
| `报告.pdf` | `报告.pdf` | 原文件保留；新文件成为 `报告 (2).pdf` |
| `报告.pdf`、`报告 (2).pdf` | `报告.pdf` | 新文件成为 `报告 (3).pdf` |
| 文件夹“照片” | 文件夹“照片” | 合并到该目录，内部重名文件继续自动加序号 |
| 普通文件“照片” | 文件夹“照片” | 无法建立该目录；查看原因后到目标网盘整理 |

重新创建一批相同的复制任务，仍会按重名规则保留新副本。**只有恢复原任务时，才依据原任务记录保留已完成结果。** 当前没有按内容去重或镜像同步功能。

### 任务完成后怎么确认

程序逐文件下载、上传并核对，再检查本批计划中的目标文件和目录。显示“已完成”表示这些检查已通过；目标原来就有的额外文件会保留，不要求整个目标目录与来源数量相等。

核验比较路径、计划文件数和精确字节大小，不是哈希或逐字节校验。完成后刷新目标列表，并在网盘官方页面打开重要文件检查内容。传输期间尽量保持源文件不变，并避免其它客户端同时写入相同目标名称。

## 四、进度、暂停和中断恢复

### 看懂任务状态

| 状态 | 含义与下一步 |
| --- | --- |
| 扫描中 | 正在读取所选文件及子目录；文件较多时需要等待 |
| 等待中 / 传输中 | 等待排队，或正在下载、上传、核对 |
| 已暂停 | 点击任务栏“继续队列”恢复 |
| 有失败项 | 点击该任务“查看原因”，处理问题后点击“重试” |
| 已完成 | 本批目录和文件检查通过，可刷新目标列表确认 |
| 已取消 | 停止该批任务，已传到目标的内容保留；账号未退出时可以重试 |

任务会显示“下载到本机”“上传到网盘”“核对文件”等阶段。整批进度主要按已经完成的文件字节数累计；正在处理一个大文件时，总进度可能暂时不变，请同时查看当前阶段和百分比。

### 暂停后继续

点击“暂停队列”会暂停整个队列。当前下载或上传不会保证立即停止，程序会在阶段结束后暂停排队；当前上传可能继续到该文件核对完成。目录扫描也可能继续完成。需要恢复时，点击“继续队列”。

### 退出或断网后恢复

1. 主窗口关闭时，若队列正在运行，会出现“继续运行”和“保存任务并退出”。选择后者会停止程序，并保留任务记录。
2. 再次双击 EXE，等待本地服务就绪，检查两边账号和文件列表。存在未完成记录时，队列默认处于暂停状态。
3. 点击“继续队列”。对显示“有失败项”的任务，先查看原因并处理，再点击“重试”。若全局仍显示“继续队列”，也要点击它才会开始传输。
4. 已记录完成的文件会保留，只处理未完成项目。单个中断文件可能重新下载或上传，不保证从中断字节继续。

断网后如果任务报错，恢复网络并检查连接，再重试原任务。若提示上传结果待确认，先刷新目标网盘核对；提交成功但响应丢失时，重试仍可能留下额外副本。

### 重试与取消的区别

| 操作 | 结果 |
| --- | --- |
| 重试 | 在原任务中重新处理未完成项，保留已完成记录；全局暂停时仍需继续队列 |
| 取消 | 请求停止当前传输并清理该任务未完成缓存；不会撤销目标中已经写入的文件或目录 |
| 重新创建任务 | 按当时选择重新扫描，会重新应用重名规则，可能生成更多副本 |

取消正在上传的文件时，远端仍可能已收到部分或全部内容，应检查目标目录。取消失败时会保留上传任务编号，请查看原因后再次点击“取消”；取消完成前不能退出账号。退出账号后已取消的旧任务不再提供“重试”，应重新选择文件创建任务。当前没有删除任务历史的界面入口。关闭主窗口会退出程序，不能把关闭窗口当成后台继续传输。

## 五、缓存、日志和本机数据

### 选择缓存目录

打开“设置”→“选择目录”。例如选择 `D:\网盘中转`，实际使用的位置为 `D:\网盘中转\OpenListTransferCache`。以设置框显示的完整路径为准。

**只有现有任务全部完成或取消后，才可更换缓存目录。** 暂停、等待、扫描和失败任务都算未完成。修改目录不会替你迁移旧缓存；需要保留任务继续处理时，先在原目录完成或重试。

### 需要多少空闲空间

文件逐个中转，通常不需要一次存下整批内容，但单个大文件可能同时占用应用缓存和引擎暂存。每个新文件开始前，软件按下面的条件检查可用空间：

**约 2.1 × 当前文件字节数 + 256 MiB。**

例如最大文件是 20 GiB，开始处理它时需约 42.25 GiB 空闲空间；还应给其它程序和失败缓存留余量。这是空间估算，不是精确峰值保证。失败缓存可能逐渐累积，遇到空间提示时按提示释放空间后重试。

上传成功并核对后，软件清理对应文件缓存。失败时可能保留缓存供重试；强制退出或崩溃也可能留下引擎临时文件。任务运行时不要手动删除缓存。需要清理残留时，先完成或取消相关任务，再关闭程序；不要删除任务记录和账号数据库。

### 在哪里找数据

| 内容 | 默认位置 / 打开方式 |
| --- | --- |
| 应用数据 | `%APPDATA%\OpenListTransfer`；设置 → 打开数据目录 |
| 默认缓存 | 应用数据目录下的 `cache`；设置 → 打开缓存目录 |
| 任务与缓存设置 | 应用数据目录中的 `tasks.json` |
| OpenList 配置与数据库 | 应用数据目录中的 `engine` |
| 事件日志 | 应用数据目录中的 `logs\events.log`；点击“查看日志”打开所在文件夹 |

`%APPDATA%` 指当前 Windows 用户的应用数据位置。可以按 `Win + R`，粘贴 `%APPDATA%\OpenListTransfer` 后回车打开。若无法打开，优先使用软件“打开数据目录”定位。

### 便携 EXE 与账号保存

EXE 无需安装，但账号状态、任务和缓存会写入本机数据目录。只移动或复制 EXE，不会同时迁移账号和任务；同一 Windows 用户再次打开时会尝试使用已有数据。

需要备份时先正常退出程序，将应用数据目录保存到自己的受保护位置。该目录含账号凭证和浏览器登录状态，数据库未提供额外的静态加密，不适合分享或上传 GitHub。当前未提供一键迁移功能；退出某个网盘账号请使用第二章的“退出当前账号”。

反馈问题时，提供软件版本、传输方向、失败阶段和“查看原因”中的文字即可。日志可能含个人文件路径，分享前先检查并遮盖敏感内容，不要发送 Cookie、Token 或整个数据目录。

## 六、常见问题与首次验收

### 遇到问题先这样处理

| 现象 | 建议操作 |
| --- | --- |
| 启动停在准备中，或显示“本地服务启动失败” | 等待首次展开完成；若明确失败，点“查看日志”，检查磁盘空间、数据目录权限及程序文件是否完整，再重新打开 |
| 登录后仍“尚未连接”，或目录读取失败 | 用官方网页确认账号正常；重新授权，或填入有效手动凭证。点击“重新加载”或刷新；115 需同时填写两种 Token |
| “到 115 / 到夸克”按钮不可点 | 确认两边均已连接、目录已加载，并在来源侧勾选至少一个项目 |
| 提示缓存空间不足 | 先在原缓存磁盘释放空间再重试；如需换盘，现有任务须先完成或取消 |
| 总进度很久不动 | 查看当前下载 / 上传阶段；大文件未完成前总进度可能不增加。出现失败时查看原因 |
| 提示源文件大小变化或源文件不存在 | 到来源网盘确认文件，取消旧任务，刷新后重新选择创建任务 |
| 目标缺失、大小不一致或目录名称冲突 | 查看原因，到目标网盘核对 / 整理冲突；软件不会将异常文件标为完成 |
| 点击“重试”后没有传输 | 检查全局是否暂停；若按钮显示“继续队列”，再点击它 |

传输先下载再上传，速度受本机网络、磁盘、账号权限和网盘服务影响。当前没有速度设置、并发设置、预计剩余时间或秒传保证；也没有本地文件上传、文件预览、删除、手动改名及新建目录的界面入口。目录可在官方客户端创建后刷新。

### 第一次正式搬运前，做一次小测试

1. 在来源盘准备一个小文件夹，内含几个小文件、一个子文件夹和一个空文件夹。
2. 先做“夸克 → 115”，等待“已完成”；确认源文件仍在，目标目录正确，文件能打开。
3. 反向做“115 → 夸克”，确认路径和内容。
4. 若需要确认重名规则，再复制一次测试文件，检查编号副本。测试中断恢复时，使用原任务继续或重试，并检查目标结果。
5. 小测试通过后，再开始大批量搬运，并为重要文件另外保留备份。

### 文档适用范围

本文对应 1.0.0 当前实现（含退出账号功能），已按源码中的按钮、任务行为和数据路径核对。项目已有自动化测试及 EXE 启动检查记录，但真实网盘登录、自动授权页面和几十到几百 GB 的云端搬运仍需用本人账号验证；“本地测试通过”不代表所有云端情况均已验证。

项目与反馈：[Wangjing991/115Toqukua](https://github.com/Wangjing991/115Toqukua)。测试范围见仓库 `docs/validation.md`，源码构建见根目录 `README.md`。本项目为第三方工具，不是夸克或 115 官方客户端。
